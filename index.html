    Placement readiness, one focused session at a time¶

    Classroom material for short, intensive placement programmes. Each page is one 60-minute session: a concept, a code template, and interview problems that students solve themselves.

    Current programme¶

    • M.Tech Placement Readiness Training

      25 hours over one week, five sessions a day. This site carries the programming foundations: Python, Linux and Git on Day 1, and data structures and algorithms on Day 2 and the morning of Day 3.

      Schedule and scoring · Setup before Day 1

    Modules¶

    • Python

      Three sessions, from the first variable to an object-oriented program that reads a CSV and handles bad input.

      Python

    • Linux and Git

      Shell commands, pipes and permissions, then the Git cycle. Students finish with their work in a public GitHub repository.

      Linux and Git

    • Data structures and algorithms

      Seven sessions taught by pattern, not by memorised answers: arrays, hashing, two pointers, binary search, stacks, trees, graphs and dynamic programming.

      DSA · Pattern cheat sheet

    How every session runs¶

    Start with the interview

    Five minutes on a real interview question that the session answers.

    See it typed live

    The concept and its code template, written in front of the class.

    Solve it yourself

    Thirty minutes of lab: one problem demonstrated, one guided, one solo.

    Debrief and commit

    Complexity, common mistakes, then a commit to the student's GitHub repository.

    What students leave with¶

    • A public record of work

      One GitHub repository with a commit for every lab and every evening practice set.

    • Patterns, not answers

      The ability to read a new problem and name the pattern it needs, with a template for each.

    • Interview language

      Practice at explaining complexity and design choices aloud, from the questions that close every session.
