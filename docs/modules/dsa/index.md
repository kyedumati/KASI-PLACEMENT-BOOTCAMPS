## How to approach any problem

Use these five steps every time, in class and in interviews:

1. **Restate** the problem in one sentence and work the example by hand.
2. **Brute force first.** Say the obvious solution and its complexity out loud.
3. **Name the pattern.** Use the [pattern cheat sheet](pattern-cheatsheet.md).
4. **Code** from the template for that pattern.
5. **Test** with the example, then an empty input, then a single element.

Problem statements on these pages are short summaries. Each links to the full statement on LeetCode, where you submit your solution.
