# Python

Three one-hour sessions that take you from your first variable to a small object-oriented program that reads and writes files.

| # | Session | You will be able to |
|---|---|---|
| 1 | [Python basics](01-basics.md) | Write programs with variables, conditions and loops |
| 2 | [Python data structures](02-data-structures.md) | Choose between a list, tuple, set and dictionary, and use each one |
| 3 | [Functions, files, OOP](03-functions-files-oop.md) | Split a program into functions and classes, read a CSV, and handle bad input |

These pages are written for a fast classroom pace. For a slower, lesson-by-lesson treatment of the same topics, see the Python section of [Full Stack Material](https://kyedumati.github.io/KASI-FULLSTACK-MATERIAL/).
