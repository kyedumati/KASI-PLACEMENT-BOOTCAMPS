# How to use this material

## In class

1. Open the day page for today from **Bootcamps**. It lists the sessions in order.
2. Open the session page when the session starts. Keep it beside your editor.
3. Type every piece of code yourself. Do not copy and paste during class.
4. Each problem is marked with how it is done in class:

| Mark | Meaning |
|---|---|
| **Live** | The trainer codes it on the projector. You type along. |
| **Guided** | You code it. The trainer gives the steps one at a time. |
| **Solo** | You code it alone. If time runs out, it becomes evening practice. |

## When you are stuck

Every problem has **hints** and a **solution**, both collapsed. Use them in this order:

1. Read the statement again and work the example by hand on paper.
2. Open hint 1 only. Try for five more minutes.
3. Open the next hint.
4. Open the solution last. Then close it and write the code again from memory.

!!! warning "Reading a solution is not solving"
    In an interview you get a blank editor. A problem counts as done only when you can write it without looking.

## After class

- Finish the Solo problems you did not complete.
- Do the **evening practice** listed at the bottom of the day page.
- Commit everything to your `placement-training-2026` repository. Daily commits are 30% of your score.

## Explain it out loud

Each session ends with interview questions. Answer them aloud, in full sentences, as if the interviewer were in front of you. Saying "it is O(n) because we visit each element once" is a skill you have to practise separately from coding.
